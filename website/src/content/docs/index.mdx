## 怎么读这门课

懂一点 JavaScript 或 TypeScript 就能跟读。每章用合成场景解释一个工程问题，给出短代码、固定提交的源码链接和一个小练习。只读网页和源码即可；若想运行练习，[源码地图](./source-map/)有测试命令，无需 Telegram 或模型密钥。
