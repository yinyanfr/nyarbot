| 术语                                                     | 在这门课里的意思                                         | 从哪里读                                     |
| -------------------------------------------------------- | -------------------------------------------------------- | -------------------------------------------- |
| **Agent · 智能体**                                       | 模型能借助工具选择接下来做什么。                         | [Agent 与 Harness](../agent-harness/)        |
| **Harness · 运行支撑层**                                 | 围绕模型安排执行、上下文、权限和投递的应用代码。         | [Agent 与 Harness](../agent-harness/)        |
| **Workflow · 工作流**                                    | 应用预先编排步骤，其中部分步骤可以调用模型。             | [日记案例](../diary/)                        |
| **Update / Handler / Turn · 更新、处理器、回合**         | 平台送来的事件、接手事件的入口、一次 AI 执行的生命周期。 | [一条消息如何变成回复](../message-to-reply/) |
| **Tool Calling · 工具调用**                              | 模型输出结构化工具请求，由应用验证和执行。               | [工具调用](../tool-calling/)                 |
| **Subagent · 子智能体**                                  | 为一个限定子任务启动的 helper；本项目将结果交回主轮次。  | [工具调用](../tool-calling/)                 |
| **Context Engineering · 上下文工程**                     | 决定给模型什么内容、怎么组织，以及怎么管理长度和可信度。 | [上下文工程](../context/)                    |
| **Late Binding / KV Cache · 后置绑定、KV 缓存**          | 临调用填入动态信息；供应商可复用输入前缀的注意力计算。   | [上下文工程](../context/)                    |
| **Compaction · 上下文压缩**                              | 将较早事件概括成工作摘要，留下近期原始事件。             | [上下文工程](../context/)                    |
| **RAG · 检索增强生成**                                   | 找到相关资料再辅助回答；这里的资料是用户记忆。           | [Memory 与 RAG](../memory-rag/)              |
| **Embedding / Cosine Similarity · 向量表示、余弦相似度** | 将文本编码为向量，按方向相近程度比较。                   | [Memory 与 RAG](../memory-rag/)              |
| **Hybrid Search / RRF · 混合检索、倒数排名融合**         | 同用关键词与向量排序，再用名次合并结果。                 | [Memory 与 RAG](../memory-rag/)              |
| **MCP · Model Context Protocol**                         | 宿主通过客户端与外部服务交换工具请求和结果的协议。       | [MCP 与多模态](../mcp/)                      |
| **Multimodal · 多模态**                                  | 模型一次接收或理解多种数据形态，例如文字和图像。         | [MCP 与多模态](../mcp/)                      |
| **Routing / Probe / Fallback · 路由、探测、回退**        | 选路径；先小成本判断是否继续；主路径失败时改走替代路径。 | [运行边界](../routing/)                      |
| **Retry / Idempotency · 重试、幂等性**                   | 失败后再试；重复操作不额外改变已完成的结果。             | [日记案例](../diary/)                        |
