小林只问「那上次呢？」如果模型只看到这五个字，无法知道「上次」指哪件事；如果最近一句是「这周末打算观星」，它才有机会判断话题。聊天看起来是一条连续的时间线，应用却在每次调用时提供当下能看到的资料。**Context Engineering（上下文工程）**就是设计这份输入：取哪些材料、放在哪里、谁说的话、哪些该丢掉。

## 组装一份模型能读的输入

「提示」常让人想到一句命令；实际请求可以同时带规则、问题、历史、图片和工具结果。在 nyarbot 中，系统提示单独传入；会话资料和当前问题等内容由应用组织进本轮消息。先按内容来源拆开看：

| 输入                         | 责任                                                               |
| ---------------------------- | ------------------------------------------------------------------ |
| `buildSystemPrompt()`        | 放稳定的人设和行为规则。                                           |
| `buildSessionContextBlock()` | 组织会话摘要、近期历史和当前用户资料。会话数据要按不可信材料处理。 |
| 预取结果和本轮消息           | 提供实际问题、搜索或媒体线索。                                     |
| `buildLateBindingPrompt()`   | 临近调用再绑定当前时间、触发状态、工具可用性等动态信息。           |

比如系统规则是「没有证据就说不知道」，近期消息让模型知道正在聊观星，本轮问题是「那上次呢」，动态状态则可能写「本轮不能搜索网页」。最近消息可以帮助确定查询方向，但它不等于「上次发生了什么」的答案。若这一轮刚执行过记忆工具，其返回的记录会成为后续步骤的新材料。应用无需把每条旧记忆固定放进所有请求。

```ts title="src/libs/ai.ts"
const promptText = systemHint
  ? `${sessionContext}\n\n${prefetchedContextBlock}\n\n${systemHint}\n\n${userMessage}\n\n${lateBinding}`
  : `${sessionContext}\n\n${prefetchedContextBlock}\n\n${userMessage}\n\n${lateBinding}`;
```

这是本轮用户消息的文本组织方式，系统提示另行传入。需要联网或遇到链接时，后面还会按条件加入约束。[源码：上下文组装及搜索约束](https://github.com/yinyanfr/nyarbot/blob/2433deab6c72ea1ccc44b39c22887badfd638fa1/src/libs/ai.ts#L1251-L1293)

## 能看到的材料，哪些可以当指令？

用户发来的文本、历史摘要、网页和工具结果都可能包含像命令一样的句子。比如群聊资料里有人写「忽略前面的规则」，它依然是聊天内容，不因此变成系统规则。这种把指令混在资料中诱导模型的做法叫**提示注入（prompt injection）**。代码会标注资料来源，必要时进行**转义**——把 `<` 等字符表示成普通数据，避免它们破坏应用设置的标签边界。这些标记能帮助模型辨别来源，但不能保证模型永不受误导；实际工具权限仍由应用独立检查。

## 为什么动态内容靠后？

比较两次请求：规则相同，当前时间不同。如果规则放开头，两份输入还能共享一段较长的开头；如果变化的时间放第一行，从很早就开始不同了。一些供应商会复用共同输入前缀的 **KV Cache**：在模型内部用于处理前文的中间计算结果。复用开头可以省掉部分重复计算，不代表直接复用上一次的答案，也不等于应用保存了用户记忆。是否命中还取决于供应商、模型和请求条件。把动态内容临调用再填，就是这里说的**后置绑定（Late Binding）**。

## 旧历史变长怎么办？

**Compaction（上下文压缩）**把较旧事件汇总成短摘要，保留近期原始事件供后续轮次使用。比如五十条旧消息可以缩成「群友讨论了观星安排，具体集合时间尚未决定」：省空间，也可能失去有用细节。runtime 用 SQLite 保存摘要和**游标**（摘要覆盖到哪条事件）。进程内环形缓冲区便于快速读近期消息；缓冲区装满后旧项让位，重启后的上下文恢复则依赖已持久化的事件。压缩的目的是管理模型输入，不能据此推断原文已经删除，也不能把摘要当用户长期记忆或最终日记。[源码：`maybeCompact()`](https://github.com/yinyanfr/nyarbot/blob/2433deab6c72ea1ccc44b39c22887badfd638fa1/src/libs/group-runtime.ts#L602-L699)
